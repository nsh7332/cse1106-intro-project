# Dice Battle

## Description
Dice Battle is a simple game where the player rolls a die against the computer. Whoever gets to 5 points first wins.

## Technologies
- C

## What the Program Does
The player and computer each roll a number from 1 to 6.

Whoever rolls the higher number gets 1 point. If they roll the same number, nobody gets a point. The game keeps going until someone gets 5 points.

After the game, the player can choose to play again or quit.

## How to Run
Compile the program:

gcc dice_battle.c

Run the program:

./a.out dice_battle.c

Press ENTER to roll the dice and follow the instructions on the screen.
